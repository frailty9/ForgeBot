# Implementation Plan（待确认）

- [x] 1. 建立引用关系与个人管理员身份前置能力
  - 为统一入站消息增加不可外部伪造的管理员标记和引用消息 ID。
  - 从 OneBot 数组段及 CQ 回退文本解析 reply ID。
  - 增加按逻辑群组作用域配置的管理员身份，并随 Runtime generation 热切换。
  - _Requirement: 3, 4, 11_

- [x] 2. 建立有界短期消息观察缓冲
  - 实现群组白名单、TTL、单群/全局容量、字符限制和并发快照。
  - 在身份解析后、Gate 与 Bot 分流前观察消息；进程重启不恢复。
  - _Requirement: 1, 2, 4, 12_

- [x] 3. 实现定时单飞 Scanner 与强关联候选规则
  - 支持热更新周期、扫描水位、终态和有限错误重试。
  - 只配对管理员显式引用且仍在缓冲中的普通成员问题。
  - _Requirement: 3, 4, 5, 11, 12_

- [x] 4. 实现受限 Reflector 与去重
  - 定义协议中立结构化结果，使用无工具 LLM 请求完成价值判断与 Markdown 整理。
  - 实现来源 ID、规范内容哈希及结构化检索辅助去重。
  - _Requirement: 6, 7_

- [x] 5. 实现 extra Markdown 安全发布器
  - 固定写入 Search 根目录下的 `extra/*.md`，执行路径、链接、大小和原子写校验。
  - 只输出受控 frontmatter 与整理后的问答，不保存整段聊天。
  - _Requirement: 8, 10_

- [x] 6. 接入批次重载、状态与通知
  - 一个批次只重载一次索引，处理部分写入失败和 reload 失败恢复。
  - 在 Runtime/admin 状态中暴露统计摘要，不暴露消息正文。
  - _Requirement: 9, 10, 11_

- [x] 7. 完成端到端与并发验证
  - 覆盖非管理员、跨群引用、过期问题、重复投递、扫描重入、热禁用、路径攻击和 reload 失败。
  - 运行竞态测试、全量测试、静态检查和真实临时文档库验证。
  - _Requirement: 1-12_

任务 2-7 在产品决策确认前不执行。
